# Task manager based on DRF

## Структура проекта:

- В основной директории находится docker-compose файл, собирающий 2 образа: django_app и db(postgres) и файл с
  переменными окружения.
- Джанго - образ содержит в себе менеджер пакетов "UV", который работает с файлом pyproject.toml и
  устанавливает все зависимости оттуда.
- Приложения разделены по сущностям для чёткого распределения и возможности масштабирования.
- Для осуществления CRUD - операций были выбраны generic - классы: ListCreateAPIView и RetrieveUpdateDestroyAPIView,
  что позволило в минимум строк кода, осуществить выполнение задач настолько, насколько это возможно. Классы обёрнуты в 
  drf_spectacular - декораторы, что позволяет работать из swagger-ui-панели.
- Пользователи создаются скриптом, а авторизоваться можно в режиме Basic auth, введя имя и пароль, 
  указанные при создании.

## Запуск

- Создаём файл .env в корне проекта, заполняем значениями как в примере(за исключением SECRET_KEY)
- Из той же директории вызываем:

```bash
docker-compose up --build
```

- Из контейнера django_app вызываем:

```bash
python manage.py create_users
```
Аналогично с другими скриптами, вложенными в директории management/commands в приложениях.
